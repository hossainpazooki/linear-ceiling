# historical-summary.json is not evidence

`historical-summary.json` is a previously reported aggregate from `neuriv/cache-injection@8e8417a`, preserved byte for byte
(sha256 `a7629b51f7bd738d7502d718eb8fa49bb12f5efbfdfea40220a507ff7f271cb6` of the committed LF bytes, 9,192 bytes; a CRLF
checkout shows a different worktree hash for the same content). Its per-example outputs, prompt caches and model downloads
were deleted, so none of its numbers can be recomputed. It is not evidence under this repository: no ledger entry, paper
sentence, README figure or review may cite a number from it. A fresh run under a registered entry is the only way any of
these quantities enters the record.

Kept by operator ruling, 2026-10-04 (PR #11, https://github.com/hossainpazooki/linear-ceiling/pull/11#issuecomment-5977752286).
